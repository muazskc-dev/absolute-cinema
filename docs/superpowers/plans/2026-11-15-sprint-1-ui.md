# Sprint 1 — Premium UI/UX and Room Experience

**Date:** 2026-11-15
**Branch:** `feat/sprint-1-ui-design`
**Spec:** `docs/design/sprint-1-visual-spec.md`
**Lifecycle contract:** `docs/rooms/room-lifecycle.md`

## Goal

Replace the red-accented Sprint 0 media deck with a monochrome, Geist-based
desktop product surface: app shell, sidebar, Home, Active Rooms, Room History,
Create/Join/password flows, Waiting Room, Cinema Room, Chat, Voice, Settings
and a reskinned Developer Lab. The mpv engine, IPC bridge, Tauri commands,
telemetry and diagnostics stay intact.

## Non-goals

- No backend, no PostgreSQL, no WebSocket room sync.
- No server-side password verification, no Argon2id implementation.
- No WebRTC or microphone permission requests.
- No embedded video in the React window.
- No push, no merge, no release.

## Tasks

1. **Foundation** — tokens, Geist imports, base styles, range control, reduced
   motion, scrollbars. No accent hue anywhere.
2. **Domain + store** — typed rooms, lifecycle union, demo seed, preferences
   (`ac.preferences.v1`), local actions: wake, create, join, simulate partner,
   disconnect, reconnect, end, rename, password, archive, delete, chat, toasts.
   Passwords stay in memory only.
3. **UI kit** — accessible dialog with trap/restore, drawer, menu, popover,
   inputs, switch, status, toasts, empty states.
4. **Shell** — 52 px header, 224/64 px sidebar with auto-collapse below 1180 px,
   native title bar untouched, page container max ~1000 px.
5. **Screens** — Home (61.8/38.2 at ≥1280), Active Rooms, Room History with
   search/filter/sort and row actions, Waiting Room (1.618/1), Cinema Room with
   real mpv bridge, Chat, Voice, Settings, Developer Lab.
6. **Prototype flows** — dormant → waking → waiting → live; live →
   reconnecting → live/dormant; create/join/password/full/unavailable/wrong
   password states. All demo-only paths labeled.
7. **Verification** — `pnpm typecheck`, `pnpm build`, Rust fmt/clippy/tests,
   media smoke tests, launch Tauri, capture real screenshots at 1280×768 and
   1100×720, 125% scaling, process cleanup.

## Rules

- Every status is icon + text, never color alone.
- `#777` only on `#000`/`#050505`; use `#a1a1aa` on raised surfaces.
- Hover 100–120 ms, dialog 160/120 ms, drawer 180 ms. Reduced motion honored.
- Shortcuts ignored inside inputs, textareas, contenteditable and open dialogs.
- Demo data is labeled in Home, History, Waiting Room, Join and Settings.
- mpv renders in a separate window; the UI never pretends otherwise.
